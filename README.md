# B2BFlow Python Supabase Z-API

Projeto Python simples que busca contatos no Supabase e envia uma mensagem personalizada via Z-API.

## Setup da tabela no Supabase

Crie a tabela `contatos` com os campos mínimos:

```sql
create table contatos (
  id bigint generated by default as identity primary key,
  nome text not null,
  telefone text not null
);
```

Exemplo de telefone: `5511999999999`.

## Variáveis de ambiente

Crie um arquivo `.env` com base no `.env.example`:

```env
SUPABASE_URL=
SUPABASE_KEY=
ZAPI_INSTANCE_ID=
ZAPI_INSTANCE_TOKEN=
ZAPI_CLIENT_TOKEN=
```

## Como rodar

```bash
pip install -r requirements.txt
python main.py
```

O envio é limitado a no máximo 3 contatos. A mensagem enviada personaliza `<nome_contato>` com o campo `nome` vindo do Supabase.

Formato:

```text
Olá, <nome_contato> tudo bem com você?
```

## Teste local

1. Crie o `.env` com base no `.env.example`.
2. Cadastre ao menos 1 contato na tabela `contatos`.
3. Rode `python -m py_compile main.py`.
4. Rode `python main.py`.
5. Confirme se a mensagem chegou no WhatsApp.
